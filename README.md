# CATRAMMY 🎵

Aplicação web de votação musical desenvolvida como projeto de estudo, com o objetivo de praticar conceitos de desenvolvimento web, back-end, banco de dados e JavaScript.

**Status: Em desenvolvimento**

Sobre o projeto

O CATRAMMY é uma aplicação que permite aos usuários participar de votações relacionadas a artistas, álbuns e músicas.

O projeto está sendo desenvolvido como parte dos meus estudos de programação e tem como objetivo colocar em prática conhecimentos de desenvolvimento web e integração entre back-end, front-end e banco de dados.

Tecnologias utilizadas

Back-end
- Python
- Flask
- Flask-SQLAlchemy
- SQLAlchemy

Banco de dados
- MySQL

Front-end
- HTML5
- CSS3
- JavaScript
- Jinja
- Chart.js

O que já foi desenvolvido

- Estrutura inicial da aplicação Flask
- Integração com banco de dados MySQL
- Modelos utilizando SQLAlchemy
- Sistema de usuários
- Estrutura de votação
- Seleção de artistas
- Seleção de álbuns
- Seleção de músicas
- Registro de votos
- Página de resultados
- Integração entre front-end e back-end
- Utilização de JavaScript para interações da aplicação

Em desenvolvimento

- Finalização do fluxo completo de votação
- Melhorias na interface
- Correção de bugs
- Melhorias na experiência do usuário
- Organização e refatoração do código
- Finalização da página de resultados

Objetivos do projeto

Este projeto tem como principais objetivos:

- Praticar desenvolvimento web
- Aprimorar conhecimentos em Python e Flask
- Trabalhar com bancos de dados relacionais
- Praticar SQL e SQLAlchemy
- Desenvolver conhecimentos em JavaScript
- Aprender a integrar diferentes partes de uma aplicação web
- Utilizar Git e GitHub durante o desenvolvimento

Status

O projeto está sendo desenvolvido continuamente como parte dos meus estudos em Análise e Desenvolvimento de Sistemas.

Novas funcionalidades e melhorias serão adicionadas conforme o desenvolvimento avançar.
